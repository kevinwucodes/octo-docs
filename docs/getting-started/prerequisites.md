# Prerequisites & Access

Before you can start contributing to our repositories, you need to set up your core accounts and request the necessary permissions.

## 1. GitHub Organization Access
*   **Account:** Ensure you have a personal GitHub account with two-factor authentication (2FA) enabled (mandatory for all organization members).
*   **Invitation:** Accept the organization invitation sent to your email.
*   **Teams:** Ask your project lead to assign you to the appropriate team repository groups.

## 2. Communication & Collaboration Tools
*   Join our primary communication channels.
*   Ensure your profile includes your real name and a professional avatar so team members can easily identify you.
